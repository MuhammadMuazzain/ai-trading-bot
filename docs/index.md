## Introduction

AI Trading Bot is a Python-based crypto trading assistant designed to support major exchanges and be controlled via Telegram or Web UI. It includes backtesting, plotting, money management tools, and strategy optimization using machine learning.

!!! Danger "DISCLAIMER"
    This software is for educational purposes only. Do not risk money which you are afraid to lose. USE THE SOFTWARE AT YOUR OWN RISK.

    Always start by running the bot in dry-run mode. Do not engage real funds before you understand how it works and what profit/loss you should expect.

    Basic Python and coding knowledge is recommended. Read the source code and understand the mechanisms before live trading.

## Features

- **Strategy development** — Write strategies in Python using pandas
- **Market data** — Download historical OHLCV data from supported exchanges
- **Backtesting** — Test strategies on historical data
- **Hyperopt** — Optimize buy/sell, ROI, stop-loss, and trailing parameters
- **Dry-run & live** — Simulate or trade with real funds
- **Control** — Telegram bot or built-in Web UI
- **Analysis** — Plot and analyze backtest and live trade history
